# PayBox Lens v0.10.0 — Lens Studio

Download, extract and start a local PayBox financial dashboard. The portable
packages include Node.js 24.21.0 LTS and the prebuilt app, so no Git, npm install,
system Node setup, external database or administrator installation is required.

## Downloads

- **Windows x64:** extract `paybox-lens-v0.10.0-win-x64.zip`, then double-click `Start-PayBox-Lens.cmd`.
- **Apple Silicon:** extract the `darwin-arm64` ZIP and open `Start-PayBox-Lens.command`.
- **Intel Mac:** choose the `darwin-x64` ZIP and the same command launcher.
- **Linux x64:** extract the `linux-x64` ZIP and run `./Start-PayBox-Lens.sh`.

The browser opens once the loopback server is ready. Keep the launcher window
open while using Lens. GitHub's automatic “Source code” archives are for developers
and do not include the runtime.

## Lens Studio

A graphite desktop shell, bright precise working surface, consistent outline icons and locally served asset artwork. Recent activity opens in a side-by-side transaction inspector with source evidence, reported network fees and a plain-English explanation. Keyboard selection and mobile stacking are supported. New installations start in light mode; existing saved preferences remain active.

The overview's wallets, cash flow and agent grants are in its expandable section. All seven pages, filters, exports, local database and connection behavior remain available. Private mode also masks the inspector.

## Included

Seven dashboard pages, wallet holdings and activity, public-chain coverage
notices, reports/exports, contacts and labels, plain-English transaction
explanations, private mode, light/dark themes and opt-in remembered PayBox
authorization. Signing and money execution remain in official PayBox flows.

Portable SQLite/key files live in the user's application-data directory, outside
the extracted version folder. Kimiloo does not receive private local data. PayBox
and public providers receive the requests required for their services. Remembered
authorization can expire or be revoked. Complete history since wallet creation is
not guaranteed.

Every Node archive is checked against a pinned official SHA-256. The release
includes ZIP checksums and per-package file manifests. Native-platform launcher,
HTTP/session/database and source/security checks gate publication. These are
portable packages, not signed desktop installers or malware-free certificates.
