# Changelog

## 0.9.0

- Portable ZIP downloads for Windows x64, Linux x64, Apple Silicon and Intel Macs.
- Bundled Node.js 24 LTS runtime verified against pinned official archive checksums.
- Ready-to-run local Worker and launchers; no Git, npm install or system Node setup required for portable downloads.
- Browser opens after the loopback server is ready.
- Portable-mode SQLite/key stored in the user's application-data directory, outside the extracted version folder.
- English beginner walkthrough, upgrade/migration instructions and release checksums.
- Repeatable packaging and a release workflow with Linux, Windows and macOS validation.
